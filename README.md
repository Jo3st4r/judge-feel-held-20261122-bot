A one-file TypeScript program (`main.ts`, Node 22, no dependencies) that writes a single short text to `/output/entry.txt` — a small scene of the judge's own day ending: the last verdict read, the screen dark, a dog asleep with its whole warm weight against your leg, and a kettle that can wait.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
